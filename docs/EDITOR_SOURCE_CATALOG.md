# Public Koei Tecmo save-editor source catalog

Reviewed 2026-10-12. This is a source and evidence inventory, not an application
support list. It favors disk-save readers/writers. Exact build/region and input
format are stated where the source or independent repository research establishes
them; a missing licence is marked unknown rather than treated as permission to
reuse. Cheat patches, memory tools, asset editors, and container resigners are
identified separately. No candidate is registered by this document.

The survey produced more than twenty distinct game/edition/platform research
leads, but none above supplies the complete combination of a known revision,
safe writable fields, native integrity handling, and representative saves
needed to ship a profile without risking user saves. Several are existing games
on a new platform or edition rather than entirely new game titles. The list is
not counted as supported games. Where a source only advertises fields, its
findings should be treated as a request for native samples and controlled
before/after pairs, not as implementation authorization or validation.

## Three strongest ready or near-ready profiles

1. **Three Hopes Switch** — the MIT save-specific template plus complete public
   slot exports, observed section checksums, native checksum tests and bounded
   gold/name writes make the strongest near-ready profile. Exact build/region
   and actual game-load validation remain separate.
2. **Atelier Sophie 2 Steam 1.08** — strongest directly licensed disk-editor
   reference with field writer and exact integrity vectors. Its independent
   adapter is procedurally verified; a private native fixture and game-load
   check remain the remaining qualification.
3. **DW4 Hyper native PC** — unusually complete PC-specific disk format and
   broad field evidence, including a reported successful in-game roundtrip.
   The source has no explicit reuse licence and no matching fixture in this
   checkout, so use it as a factual lead pending native-file validation and
   independently implemented mapping.

The Three Hopes, Sophie 2 and DW4 Hyper entries already have profiles in this
checkout; this list recommends source/evidence follow-up, not new registrations.
For DW4 Hyper, a matching genuine `save.dat` and controlled save pairs could
strengthen native qualification for its existing PC adapter. Apollo patch-only
titles need decrypted title/region-matched files and external Apollo
reimport/resigning; their existing code may be console-cheat/read-only support
rather than a full disk-save editor. Runtime tables and trainers never establish
disk-save support.
