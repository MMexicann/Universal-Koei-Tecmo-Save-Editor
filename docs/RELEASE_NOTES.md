# Universal Koei Tecmo Game Toolkit v1.0.1

Linux support and connected toolkit workflows, with existing save compatibility preserved.

- **Linux edition:** native x86_64 GUI and headless CLI builds, Linux CI,
  reviewed runtime dependencies and Steam discovery for standard, XDG and Flatpak installations.
- **Connected mod tools:** separate Nioh 2 and Nioh 3 PC installation methods,
  per-game libraries and profiles, and Workshop exports that import directly
  into the matching Mod Manager library.
- **Clear Nexus workflow:** each game shows its actual installation support;
  supported downloaded ZIPs can be imported from the Nexus page. Integrated API
  browsing remains unavailable pending application registration.
- **All tools in one place:** searchable Tools navigation with game and platform
  limits, plus menu and command-palette access to previously separate tools.
- **Bundled browser workspaces:** launch Mod Testing Sandbox and Localization
  Studio from the application without Node or a separate server.
- **Desktop research tools:** search the edition-scoped encyclopedia and compare
  explicit patch snapshots with reviewed JSON/Markdown exports.
- **Troubleshooting and usability:** native bounded Windows folder scans,
  safer profile storage and report exports, and improved small-window layouts.
- **Mod CLI:** inspect supported methods, validate/import local archives, and
  review/export Workshop packages without deploying mods.

**98 save profiles · 15 save platforms · 145 scoped conversion routes.**
No new save-editing profiles are implied by the additional mod adapter.
Save Vault, Playthrough Profile storage and game mod deployment remain Windows-only.
Actual edited-save and mod loading in games remain unverified.
