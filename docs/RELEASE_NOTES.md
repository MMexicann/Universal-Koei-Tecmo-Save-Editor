# Universal Koei Tecmo Save Editor v2.6

Add useful tools around editing and expand the library to **97 game/platform
profiles across 15 platforms**. Conversion routes remain 139. The GitHub landing
page is shorter; the full supported-games list now has a platform index and
separate platform sections.

## Save management and editor tools

- **Save Library:** choose one exact game/platform, scan a copied-save folder,
  search/sort/filter results and find identical gameplay files. Optional bounded
  subfolder scanning, cancellation and fresh validation before opening are
  included. Files and account context are not moved, deleted or repaired. DW3's
  separate editor is excluded from this browser.
- **Edit Presets:** export alternative edit plans for the exact original save.
  Import previews opened, current and resulting values for the complete pending
  batch; deliberate Apply is one Undo action. Presets bind to the game, original
  bytes and field definitions. They do not transfer edits to other saves or
  save automatically.
- **Pinned fields:** pin frequently used fields per exact game/platform and
  filter to them. Unavailable dynamic fields stay hidden without losing pins.
- **CSV reviews:** export complete frozen change snapshots with typed raw values,
  named before/after labels and spreadsheet-safe text. Copy Selected is available
  in Review Changes. JSON reviews and automatic report suffixes remain available.
- Retain browser, comparison, conversion, queue and editor sessions when changing
  workspaces. Ctrl+F follows the active workspace. All fourteen reviewed user
  guides are included in both Windows build forms.

## New titles and deeper existing editors

- **Warriors: Legends of Troy, original EU PS3:** existing Kleos reductions in
  the exact revision-38 populated PROFILE, plus 152 literal native music/item
  records. Original PARAM.SFO is required; PFD reimport/signing stays external.
  Higher ambiguous wallet words remain read only.
- **Orochi Z PC:** independently bounded base Life, Musou, Defense and Speed
  alongside Attack. Individual native floors/ceilings and unusual originals are
  preserved; weapon effects and level transitions remain separate.
- **WO3 Ultimate PC:** explicit existing weapon compatibility reset to zero,
  pending-aware ordinary-item choices and a separate 64-record item inventory.
  Arbitrary compatibility increases are not enabled.
- **WO3 Ultimate US PS3:** verify source/context freshness and actual created
  files through backup, Save As and restore; preserve completed files after a
  late failure.

## Validation and limits

The new adapter qualifies native copied exports and preserve unknown bytes, original
context and full native integrity. Troy evidence is **one gameplay state in two
representations**. Fatal Frame II PS2 research independently qualifies native
container/checksum geometry, but the proposed inventory writer remains
unregistered and excluded pending retail save-linkage/dependency proof. Exact
qualification and remaining boundaries are documented in the format guides.

Independent review tightened cancellation, root-folder replacement, source
postflight checks, preset mapping drift and copy-output races. Full source and
Windows test coverage, both packaged startup checks, active Defender scans and
exact public-download verification remain mandatory release gates.

**Edited or converted game loading/re-saving remains untested.** Origins weapon
proficiency-level and Old Coin writers remain unimplemented. DW7 XL PC arbitrary
weapon base attack/element/capacity edits remain unavailable through the save.
A universal mod installer or game-asset editor is not included in this release.
