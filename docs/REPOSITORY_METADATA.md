# GitHub repository identity

The application is **Universal Koei Tecmo Save Editor**, by **Mexican**.
The repository is [MMexicann/Universal-Koei-Tecmo-Save-Editor](https://github.com/MMexicann/Universal-Koei-Tecmo-Save-Editor).

GitHub's About description and website are separate from source documents.
Maintain them when the published feature scope changes; updating a README alone
does not update repository settings. Keep the description concise and identify
supported game families, the Windows app and safe editing workflow.

Contributor entry points remain [CONTRIBUTING.md](../CONTRIBUTING.md) and
[AGENTS.md](../AGENTS.md). The [documentation index](README.md) and
[generated game inventory](SUPPORTED_GAMES.md) describe the organized source.
The README and release notes describe user features; format proof, licences and
remaining inputs belong in coverage/validation documents.

Use the normal repository workflow and respect branch protection. Before
reporting a release complete, verify the public version, description, release
notes, standalone Windows EXE and Windows ZIP downloads. Record checks actually
performed rather than treating prepared text or a successful push as publication.
