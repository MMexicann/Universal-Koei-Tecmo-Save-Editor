# Universal Koei Tecmo Game Toolkit v1.0

**Development preview; publication is on hold.** [Current Windows download: Save Editor v3.1](https://github.com/MMexicann/Universal-Koei-Tecmo-Save-Editor/releases/latest).

- **New name:** Save Editor becomes Game Toolkit. The v3.1 → v1.0 version reset
  preserves existing features, save compatibility and project history.
- **Save workflows:** Smart Playthrough Profiles prepare isolated copies;
  improved paging, search, comparisons and reviews retain backups and Undo.
- **Character & Weapon Workshop:** plan and compare mapped builds for DW3
  Remastered, DW8 XL PC, WO3 Ultimate PC and SW4 DX PC.
- **Mod tools:** create replacement packages and manage Nioh 2 PC Mods-folder
  packages with profiles and dependency/conflict checks. A browser-local Sandbox
  provides separate source tools and reviewed file handoffs.
- **Game and asset tools:** Steam Game Hub, version observations, emulator
  profiles and read-only ZIP, G1T and common-media previews. Controller profiles
  store local notes; Nexus provides website links while API access is gated.
- **Progress and inspection:** Completion Companion, strategy record views,
  read-only Nioh 3 equipment details and clearer Project Zero PS2 film labels.
- **Source tools and reference data:** offline Localization Studio for supported
  text tables, data-only community packages, a snapshot-based patch analyzer,
  and Three Hopes Switch/Hyrule Warriors Wii U reference data.

**98 game/platform profiles · 15 save platforms · 145 scoped conversion routes.**
This update adds no new save-editing profiles or platforms. See the
[exact game catalog](SUPPORTED_GAMES.md).

Edited/converted in-game loading remains unverified. Research edition leads do
not imply editing support; Windows Troubleshooting folder scans remain unavailable.
[Compatibility and limits](../README.md#compatibility).

These notes remain provisional while reviewed changes merge into `main`.
