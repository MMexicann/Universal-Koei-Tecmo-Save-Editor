# Universal Koei Tecmo Game Toolkit v1.0

**Pending release.** These notes cover integrated development source only.
[Download the current Save Editor v3.1](https://github.com/MMexicann/Universal-Koei-Tecmo-Save-Editor/releases/latest).

- **New identity:** Universal Koei Tecmo Save Editor becomes **Universal Koei Tecmo
  Game Toolkit**. v1.0 is a branding version reset after v3.1; earlier releases,
  repository history and existing save-editing support are retained.
- **Strategy views:** read-only Scenario View cards show existing province, city,
  officer and military-district records across six strategy profiles. Editing
  remains limited to each profile’s existing controls.
- **Integration groundwork:** a DW3 Remastered Steam achievement backend and
  edition-scoped Three Hopes/Hyrule Warriors reference data. Achievement lookup,
  encyclopedia browsing and Character Workshop interfaces are still pending.
- **Existing toolkit capabilities:** save editing, dashboards, Save Library/Doctor/Vault,
  comparison, scoped conversion, presets, reviewed automation and community plugins
  continue under the new name, with backups, Undo and Review Changes.
- **Game coverage:** 98 game/platform profiles across 15 save platforms and 145
  scoped conversion routes. No new game profiles or platforms are integrated
  beyond v3.1 at this stage. [Exact editions and controls](SUPPORTED_GAMES.md).

File-level validation is documented per profile; edited/converted in-game loading
and re-saving remain unverified. Console preparation/signing uses external tools.
Experimental numeric editing is opt-in; research imports remain read-only.
[Compatibility and limits](../README.md#compatibility).

Final publication awaits completion of the development workstreams, integration
review and the required Windows build, testing, security and licensing checks.
