# Universal Koei Tecmo Save Editor v2.7

Explore verified save information through graphical progression dashboards.
The library remains **97 game/platform profiles across 15 platforms**, with
139 scoped conversion routes. This update adds presentation and navigation;
existing save mappings, editing limits and conversion scope remain intact.

## Graphical progression dashboards

- **Modern cards:** searchable records, section navigation, responsive card grids,
  verified progress bars, selected-record details and bounded paging for large
  equipment inventories. Full Light/Dark appearance includes the drawn graphics.
- **Direct editing navigation:** follow a mapped value to its original editable
  field. Browsing, filtering and selecting cards never stages an edit.
- **Dynasty Warriors 8 XL PC:** officer levels, experience and permanent stats,
  verified four-star weapon aptitude, saved weapon references, populated weapons
  and attributes, resources and separate physical ally records.
- **Warriors Orochi 3 Ultimate PC:** officer levels, experience, promotions and
  stats; weapon attributes, reinforcement and raw compatibility; item ownership,
  ranks and equipped references; mount loadouts and resources. Collection progress
  covers the explicitly mapped ordinary-item and mount ownership flags only.
- **Dynasty Warriors: Origins:** existing named bonds, resources, occupied weapon
  records and traits, provincial peace, mapped battle clear history and stored
  proficiency XP/Battle Arts where the record layout qualifies.
- **Dynasty Warriors 3 Remastered:** named officer cards, permanent stats, saved
  weapon references, owned weapon details, available Elixir balance, individual
  Musou routes and mapped galleries through its existing tagged editor.
- **Other scalar profiles:** cards retain all mapped opened values, grouped by
  native record/category, with search and direct field links.

Dashboards display the **opened save snapshot**. Pending edits remain in Edit
Fields and Review Changes; saving a new copy refreshes the snapshot. No XP-to-level
threshold, unlock state or overall completion percentage is guessed. Numbered
physical records remain numbered where character identities are not mapped.

## Contributor work and validation

Sanrenan's reviewed PR #43 adds optional genuine-file regression coverage
for DW7 XL PC seal-meter reductions, preserving contributor attribution. The
generated-manifest conflict is resolved against current main, and the docs
distinguish the contributor-reported positive native state from independently
reproduced tests.
The contributor's eligible private fixture is not included in public sources.

Existing backups, immutable source copies, Undo, edit presets, reviews and guarded
Save As remain available. Release gates require the complete source and Windows
suites, both packaged startup checks, active Microsoft Defender scans and exact
artifact-integrity verification before publication.

**Edited/converted in-game loading and re-saving remain unverified.** Origins
proficiency-level and Old Coin writers remain unavailable; displaying stored XP
does not implement those requests. DW7 XL arbitrary weapon base-parameter editing
is outside the qualified save mappings. See the [dashboard guide](https://github.com/MMexicann/Universal-Koei-Tecmo-Toolkit/blob/v2.7/docs/PROGRESSION_DASHBOARDS.md)
for exact coverage and interpretation.
