NIOH 2 MOD MANAGER · ZIP IMPORT
Manager-compatible packages
Download one validated Nioh 2 mod at a time. The sandbox blocks export when its required staged dependencies or destination checks fail. Import the ZIP into the manager library for its own package checks; the sandbox never selects a game folder or applies a package.
01Manager package rulesExactly one `.ini`, at least one `.fmt`, `.vb`, `.ib`, or `.dds` asset, and all files inside the `.ini` marker folder.
02Dependency and build limitsManager metadata stores dependency IDs only, so required version ranges block export. The selected game build is not recorded or verified by the manager package.
03Revalidation and install confirmationThe manager verifies package bytes, then separately requires its loader and game-closed confirmation before file changes.

SAFETY MODEL

        
Your game stays
untouched.

        
01Browser-local staging
Files stay in this browser’s isolated workspace, in separate game and mod-ID namespaces. IndexedDB persists across reloads; if it is unavailable, files stay in tab memory. No mod file is uploaded.
02Data only
Manifests are parsed as JSON. Imported files are never executed, evaluated, or launched.
03Review before export
Unsafe paths, missing files, incompatible game/build declarations, hash mismatches, and collisions block package creation.
04Confirmation gate
Export requires a separate confirmation and creates a ZIP download only. The sandbox cannot write to your original game installation.
